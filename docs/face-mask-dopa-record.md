# Face Mask × Dopa Record — rc.13

スマホを置く → 好きなだけ運動する → 自分・音楽・世界が育つ → 自分で運動を終了する → Beginning → Growth → Peakの動画を受け取る。

**Dopa Recordは運動時間を短縮させる動機を作らない。** Free Flowには時間制限がなく、素材の充足は終了条件にならない。3分コースは別の明示的な運動設定。Recordは開始前だけONにでき、ページを開いた時はOFF。ONの設定は永続化せず、同じ画面の「もう一回」では選択中のONを引き継ぐ。運動中に動画の達成率・完成通知・保存の誘導を出さない。

## マスクなし録画 / 2026-10-03

RecordとFace Maskを独立して選べる。MY ROOMではMask OFFのカメラ映像を録画でき、顔も映ることを録画設定に表示する。Mask OFFではFaceモデルを起動せず、専用Canvasへ現在のカメラ表示と同じ左右反転・cover／containで映像を描き、ゲーム演出とゲーム音を収録する。Mask ONでは従来の顔カバー・鮮度・退避条件を維持する。BLUR ROOM／DOPA STAGEは引き続きMaskを併用する。Record ONは永続化しない。

## 実装

- `game.js`：獲得済みstageLevel、表示中presentedStageLevel、cycleIdを分離。100 ENERGYで成長し、Pause／RESTで下がらない。HIT音は獲得段階を即時反映。音楽と仮面・色の表示は小節頭に同期する。SUPERNOVA以降もENERGYを繰り越して波を繰り返し、流星・光輪・左右ウェーブ・星雨の変奏を循環する。
- `face-tracker.js`／`face-worker.js`：Detector／Landmarkerを同じ入力幅・CPU delegate・顔カバーに接続。方式は**未確定**で、初期のDetectorは仮の実装候補。`?faceTracker=landmarker`でも切り替えられる。推論はWorker内、転送中のフレームは1枚だけ。両方式の入力幅は384px、要求間隔は100ms以上。選択した背景のモデルは初期化中に読み込み、初回フレームのタイムアウトを避ける。初期化失敗やWorker停止後は自動で再試行する。
- `safe-scene.js`：同じ凍結フレームの追跡結果を使い、非公開Canvasで不透明な顔カバーを先に描く。装飾や回転で穴を開けない。顔周辺の不透明カバーは検出枠の幅1.20倍・高さ1.24倍に収め、胸元や手を覆う余白を減らす。FEVER装飾はカバー内にクリップし、横や上へ張り出さない。手の位置には前面の手形カーソルと肩・肘からの腕の線を描く。腕の線は200ms以内の有効なPoseだけで描く。顔カバー内へ実写の手を復元する処理は行わない。未検出・複数人・異常値・200ms超・画面を覆う大きすぎる顔検出では実写を遮断し、Poseに追従するアバターと原因に応じた案内を表示する。この区間は録画候補に含めない。次の推論の処理待ちでは、すでに顔を隠した同一スナップショットだけを撮影から最大450msまで表示してちらつきを抑える。新しい不適合結果を受け取れば直ちにアバターへ切り替え、表示保持で復活させない。録画は引き続き撮影から200ms以内に限定する。MY ROOM／BLUR ROOM／DOPA STAGEのプレビューと録画は同じ合成結果を使う。背景分離に失敗してもMY ROOMへ戻さない。固定したSelfieSegmenter v1の単一selfie信頼度出力を使い、背景と人物の判定を作る。
- `highlight-budget.js`：未知端末はLOW 24MiB。検証済みの上限を渡した場合だけNORMAL 48MiB／HIGH 64MiBへの昇格を許す。10秒悪化で降格、60秒安定で昇格。保持素材、メタデータ、収録中の予約、Plannerメタデータを容量に含める。モデル・Canvas・ネイティブエンコーダのメモリは別に実測が必要。
- `record-session.js`：独立再生可能な約4秒のクリップごとにMediaRecorderを開始／終了する。録画対応とは別に編集用デコード対応も確認し、MP4素材を編集できない環境では対応するVP8／Opus素材を選ぶ。timesliceは容量監視に使い、同じ録画内の断片から1つの完成クリップを確定する。別録画の断片を単純連結しない。マイクは要求せず、ゲーム音の出力だけを収録する。操作UI・診断表示は収録しない。
- `highlight-planner.js`：品質ゲートの後、序盤・進化・最高段階を確保する。動き・HIT密度・進化・新規性・時間重複・同一Cycle・動作／方向・構図・変奏の類似を使って追加価値を評価する。同一FEVERを原則2区間・12秒以内にし、素材が足りない場合だけ緩和する。時間順を維持し、実際の進化オフセットを含む位置で切り出す。未到達の段階を捏造しない。
- `video-exporter.js`：Mediabunny／WebCodecsを優先し、MP4が利用不可ならWebM。非対応時はクリップを順にCanvas再生し、ゲーム音をクロスフェードしてMediaRecorderで再書き出しする。書き出し状況を表示し、失敗しても集計と選択素材を保持して再試行できる。OS共有キャンセルでも完成動画は残る。

`record-config.js`に標準尺、締め、物語の比率を集約する。UIの標準は45秒。内部の15／30／45／60秒選定を同じPlannerで検証する。素材不足ではその素材だけの短編を作り、フレームの重複や引き伸ばしで埋めない。

## 固定上限と解放

- 候補は最大48個、各候補のメタデータは最大4096 bytes。新しいクリップの予約は1.5MiBで、超過した収録は破棄する。
- アンカー全体は最大12MiB。同じ役割の代表だけを残す。直近2クリップを短いバッファとして保護し、古さだけで序盤や成長を捨てない。
- 使用率80%から整理し、品質・類似・追加価値が低い候補を先に解放する。降格しても保護素材を失う場合は追加を見送る。
- 顔推論フレームは1枚。書き出しは1クリップずつ、映像・音声を同期して処理する。高速経路のPCMは1クリップ4.25秒以内、クロスフェードの持ち越しは40ms。再生経路の動画／音声の先読みは次の1クリップだけ。固定版Mediabunnyのデコーダ待ちは、デコード済みサンプルがある場合8、それ以外はエンコード済みパケット40のキュー制御を使う。ブラウザ内部の追加バッファは実機メモリ測定の対象にする。
- 出力は別枠で最大20MiB。高速経路は256KiBページとストリームのバックプレッシャーを使い、全素材を一括展開しない。
- 破棄時にBlob参照、Object URL、Bitmap、フレーム、録画トラック、再生・音声ノードを解放する。別の運動を始めると編集中処理を中止し、前回の一時素材を破棄する。履歴は従来の集計と互換性を保ち、動画を永続保存しない。
- 追加モデル／ライブラリは同一配信元の固定版、約28.5MB。ハッシュ検証済みの独立した任意キャッシュで、従来のオフライン起動を妨げない。動画を書き出している間はPWA更新を待機する。

## 検証と残る実機受入

自動試験は `npm test` と `npm run test:record-browser`。通常のカメラ・準備・HIT・音楽・履歴・PWAの既存試験も維持する。

単体試験で3分／10分／20分／20時間相当の候補流、LOWへの降格、予約と上限、アンカー保護、多様性、全4種類の尺、短編、品質不良、500→800 ENERGYと変奏を検証する。これらは**合成試験**であり、スマートフォンのプロセスメモリ測定ではない。

ブラウザ試験では実際に独立クリップを収録し、Pauseから音声を再構築し、MP4を編集・再生・保存する。書き出した音声をデコードしてゲーム音が存在することを確認する。50秒以上の素材が集まっても運動は続き、Finish操作で45秒の成長動画になることを確認する。Canvas経路と、3背景の顔カバー・遅延・背景分離失敗時の不透明な退避も確認する。

提供された静止画像は、ローカルだけのDetector／Landmarker起動・顔検出・合成確認に使える。画像はリポジトリや配布キャッシュへ追加しない。この静止画像試験を、運動中の追従品質や実機の顔露出ゼロの証明として扱わない。

**iPhone Safari／ホーム画面PWA／Android Chromeでの3・10・20分の受入は未実施。顔追跡方式の採用と、端末プロファイルの昇格は保留。**

実機比較は `?debug=1` の「Face Tracker PoC」で方式を選び、同じ背景・Pose・Record設定で別セッションを実行する。横向き、傾き、急な動き、追跡喪失、再検出、複数人、Pauseの各状況を観察し、機種・OS・位置／回転のずれ・顔露出の回数を記録してJSONを保存する。固定サイズのヒストグラムで顔／Pose遅延を集計し、長時間のイベント列を保持しない。CPU／GPU使用率、プロセスメモリ、発熱は外部の端末計測を記録する。

採用条件は、顔露出が観測されず遮断が機能すること、描画24fps以上、Pose p95 150ms以内。その後に追従の改善と負荷を比較する。両方式とも満たさない場合は画質・演出を下げて再評価する。実機結果を得るまでは合格・確定採用と表示しない。

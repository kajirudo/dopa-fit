# Dopa Feedback / Phase 3 — rc.11

## 今回の体験

「動いた結果がすぐ返る → 成長が見える → 盛り上がる → ひと息 → また盛り上がる」という流れを強めます。狙いは音と光の反応、積み重ねの達成感、音楽の変化です。

- HIT：約75msで円が収縮し、局所的な白フラッシュは80msで消え、三重リングは280msで収束。合成音は190ms、粒子は約200–300ms。手のTrailは直近240ms。判定と音は同じイベントから即座に開始する。
- 強さ：肩中心からの手首速度で音・粒子・リングを最大35%増幅する。弱い動作も基本の演出とHIT +5を返す。
- ターゲット：左右4段ずつ、通常8か所の候補から配置。映像端で重なる候補は除外。通常・ひと息で触れるターゲットは最大2個、NEXT予告は最大1個。FEVERは4／6／8／10／12個を上限に、届く範囲で重ならない数を配置（[2026-10-02の改善](calibration-fever-improvements.md)）。片側のHITで反対側をGOと強調し、打った側は350ms以上先の拍で次の高さへ入れ替える。順番・手・速度・拍の一致は要求しない。
- 予告：到着位置の破線円とNEXTを表示し、小さな独自タイルが奥から近づく。予告は判定しない。到着後は一定半径のターゲットと手の周辺の円が重なればHIT。表示タイルはターゲットの円内に収まる。手首から手先へ肘を基準に補正し、半径20〜40pxの手の周辺判定を表示する。新しく現れたターゲットと既に重なっている手、200ms超の古い推論結果はHITにしない。手首が欠けてもマーカー表示は最大320ms保ち、肘が追えている場合のみ最大220msの動き補助を使う。表示保持だけで加点しない。
- リズム：音が有効なときは予約済み音声の時計で出現と拍動を合わせる。音声復旧・予約の遅延回復後も時計を再対応させる。音が有効でない場合はプレイ時間へフォールバック。HIT音は拍まで待たず即時。
- 配置：半身の縦方向は画面幅に合わせて縮めず、実際の肩幅と可視領域から上・中央・下の4段を作る。HUD下の左上にマスコットを置き、その高さをターゲット配置から除外。短い横画面、ターゲットやお祝いと重なるときは表示しない。
- 展開：通常は左右→上→下へ高さを変え、FEVERでは左右の高さを違えて対角の動きを誘う。RESTは中段と下段。取り逃した場合も約8拍後に静かに次へ移り、RESTは12拍の余裕を持たせる。減点・失敗音・成果リセットなし。
- 範囲：Pauseで「広く動く／その場で小さく」を選ぶ。小さくでは肩を基準に配置の広がりを68%へ縮め、次の再開・キャリブレーションで適用する。加点と接触半径は変えない。
- UI：カメラステージを表示領域いっぱいにし、通常はENERGY・現在の解放音・Pauseだけを表示。縦向きカメラをideal条件で要求する。標準はcoverで上下の余白をなくし、切り抜きと鏡座標を同じ変換にする。半身モードの推論は元のカメラ全体を使用し、切り抜き外の肩・肘も体格基準に使う。全身モードのcover推論は可視範囲を最大640pxで切り抜く。Pauseの「広く映す」でcontainへ戻せる。音量・音を試す・全レイヤー・記録値・終了はPause内へ移す。音が開始できない場合だけ復旧へのボタンを表示。
- 成長：楽器が解放されるとNEW SOUNDと短い上昇音。音楽の編成は従来どおり小節頭で追加。
- 累積：TOTAL HITSをPause内に表示。5／10／20／30／40／50、その後25HITごとに節目を祝う。同時解放時はお祝いの字幕へHIT数を統合する。
- 期待：次のFEVERまで75 ENERGYに到達すると予告。進捗バーと残りENERGYを温かい色へ。
- 遊び方：半身／全身を開始前とPauseで選択。半身は近距離で肩幅が画面を超えても開始でき、ターゲットの配置幅と半径を表示領域へ合わせる。腰の加点なし。全身は腰まで映る配置で開始。約60cmは実機確認が必要な目安で、距離を計測・保証しない。
- FEVER：SPARK／GROOVE／RUSH／HYPER／SUPERNOVAの5段階。100 ENERGYごとにひとつ育ち、120／128／138／148／160 BPMで加速し、四つ打ち→跳ねるリズム→共鳴ベースと16分リード→シンコペーションと和音→高速リードと和音へ変える。通常112 BPM、ひと息100 BPM。5色の光も段階的に変化。余剰ENERGYを繰り越し、到達段階はセッション内で保持。最高段階でもプレイを継続できる。大きなタイトル、紙吹雪、ゆっくり回る光線、ビート連動の光とバー、残り秒数。HIT音を明るい音域へ、メロディを16分音符、ベースを8分音符へ増やす。
- 波：段階のテンポで8小節相当のFEVER（約12〜16秒）後は100 BPMで4小節相当の穏やかな編成とNICE FLOW。切替は次の未予約の小節頭で、状態と実際の音に最大1小節程度の差がある。光の拍とターゲット交換は音声時計に追従。累計成果と解放済み楽器を保つ。

演出は独自Canvas／CSSと既存の独自マスコット。録音素材、第三者画像、フォント、依存、外部通信は追加しません。Beat Saberのリズムに沿って動作をつなぐ体験も設計の参考にしています。コード・譜面・楽曲・画像・ロゴは取得・改変していません。Dopa Fit独自のタイルとパターンです。

## 演出と動作の境界

画面やカメラを揺らす処理は使わず、判定座標を維持します。背景の光は低い不透明度で滑らかに変化し、強い全画面点滅は使いません。TOTAL HITSは連続コンボではなく、休憩でも消えません。

粒子は通常160、FEVER240、負荷低減時80。効果を連続発生させても上限を超えず、終了後に消えます。音声は既存の24voice／160AudioNode上限を共有し、HITを優先します。低負荷設定では光線の本数も減らします。

「演出ひかえめ」ではターゲット収縮・白フラッシュ・紙吹雪と回転光線・背景の拍動・Trail・入口アニメを抑え、設定直後に既存の粒子を消します。加点、音、文字、ターゲットは残します。OSの減らす設定を初期値に反映します。

## 次に提案する改善

| 優先 | 改善 | 体験と評価方法 |
|---|---|---|
| 1 | 動作ごとの音色 | 手振り＝メロディ、両手上げ＝シンバル、ステップ＝ベース、上下動＝和音。フォーム採点をせず、自分で編成を操る感覚を評価する。 |
| 2 | 3分で展開する楽曲 | 導入→成長→FEVER→余韻を3分コースに合わせる。Funk／House等の独自パターンを用意し、同じ音のループによる飽きを減らす。 |
| 3 | 自由ダンスモード | 円を狙わず、届く範囲の動きで音をつくる。認識の安定性、初心者が説明なしに始められるかを評価する。 |
| 4 | 演出の3段階設定 | おだやか／ふつう／派手。実機の発熱と描画遅延を比較して、端末に合う予算を選ぶ。 |

追加前に、今回の版をiPhone／Androidで3分→10分→20分と評価し、HITの遅延、音の密度、ターゲットの見やすさ、発熱を記録します。描画のために推論や音が遅くなる場合は演出を調整します。

## 最初の一歩を分かりやすく

日本語／英語を端末の優先言語から選び、トップ・Pause・準備中に変更可能。読みやすいモバイル説明と翻訳したPrivacyを用意。準備中は映像をぼかさず、肩・両手・全身の腰のチェックと安定待ちの進捗を示す。姿勢の例は正確な一致を要求しない。足りない部位を短く案内し、腰が映らなければその場で半身へ切替可能。準備が整うと例とチェックを片付け、3秒と「光るターゲットへ」を表示。認識条件・加点・テンポは変更しない。

## rc.12：導入・タメ・成果

最長10秒の練習で大きめの左円→右円へ触れる。各1HITで早期終了、スキップ可。練習中も通常の成果を加算し、認識欠落や休憩で失敗を出さない。Pause中は秒数を進めず、再調整でも進捗を保つ。通常の広い運動範囲やHIT判定は変更しない。

FEVER前は1小節（112 BPM、約2.14秒）の上昇シンセと加速スネア、BGM Gainの絞り込み。次の小節でキック・シンバル・和音と各段階のテンポへ切り替える。実際の音声時計が突入を示す時にリング拡散・紙吹雪・タイトルを一度返し、そこから8小節相当のFEVER時間を数える。音が開始できない場合も運動と視覚FEVERは継続。HIT音はタメ中も即時。上限・演出ひかえめを維持。

終了時は最高FEVER、HIT、ENERGY、時間を720×900の独自Canvasカードへ。端末内でPNG保存でき、集計とマスコットだけを使う。カメラ写真なし。再プレイはクリック内で音声を起動し、新しい練習と成果から開始。日本語／英語。

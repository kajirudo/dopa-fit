# Dopa Feedback / Phase 3 — rc.5

## 今回の体験

「動いた結果がすぐ返る → 成長が見える → 盛り上がる → ひと息 → また盛り上がる」という流れを強めます。神経伝達物質の分泌量を測定・保証する機能ではありません。狙いは音と光の反応、積み重ねの達成感、音楽の変化です。

- HIT：二重の衝撃リング、放射状の光、大きなHIT +5、増量した粒子。
- 成長：楽器が解放されるとNEW SOUNDと短い上昇音。音楽の編成は従来どおり小節頭で追加。
- 累積：TOTAL HITSを常時表示。5／10／20／30／40／50、その後25HITごとに節目を祝う。同時解放時はお祝いの字幕へHIT数を統合する。
- 期待：次のFEVERまで75 ENERGYに到達すると予告。進捗バーと残りENERGYを温かい色へ。
- FEVER：大きなタイトル、紙吹雪、ゆっくり回る光線、ビート連動の光とバー、残り秒数。HIT音を明るい音域へ、メロディを16分音符、ベースを8分音符へ増やす。
- 波：8小節のFEVER後は穏やかな編成とNICE FLOW。累計成果と解放済み楽器を保つ。

演出は独自Canvas／CSSと既存の独自マスコット。録音素材、第三者画像、フォント、依存、外部通信は追加しません。

## 演出と動作の境界

画面やカメラを揺らす処理は使わず、判定座標を維持します。背景の光は低い不透明度で滑らかに変化し、強い全画面点滅は使いません。TOTAL HITSは連続コンボではなく、休憩でも消えません。

粒子は通常160、FEVER240、負荷低減時80。効果を連続発生させても上限を超えず、終了後に消えます。音声は既存の24voice／160AudioNode上限を共有し、HITを優先します。低負荷設定では光線の本数も減らします。

「演出ひかえめ」では紙吹雪と回転光線・背景の拍動・Trail・入口アニメを抑え、設定直後に既存の粒子を消します。加点、音、文字、ターゲットは残します。OSの減らす設定を初期値に反映します。

## 次に提案する改善

| 優先 | 改善 | 体験と評価方法 |
|---|---|---|
| 1 | 動作ごとの音色 | 手振り＝メロディ、両手上げ＝シンバル、ステップ＝ベース、上下動＝和音。フォーム採点をせず、自分で編成を操る感覚を評価する。 |
| 2 | 3分で展開する楽曲 | 導入→成長→FEVER→余韻を3分コースに合わせる。Funk／House等の独自パターンを用意し、同じ音のループによる飽きを減らす。 |
| 3 | 自由ダンスモード | 円を狙わず、届く範囲の動きで音をつくる。認識の安定性、初心者が説明なしに始められるかを評価する。 |
| 4 | 演出の3段階設定 | おだやか／ふつう／派手。実機の発熱と描画遅延を比較して、端末に合う予算を選ぶ。 |

追加前に、今回の版をiPhone／Androidで3分→10分→20分と評価し、HITの遅延、音の密度、ターゲットの見やすさ、発熱を記録します。描画のために推論や音が遅くなる場合は演出を調整します。
